# yt-dlpjson2nicojson
Convert the niconico comment file downloaded with yt-dlp to a new comment file a compatible with nicojson2xml

YouTube live chat replay files (`*.live_chat.json`) downloaded with yt-dlp are also supported.

```
python yt-dlpjson2nicojson.py input.json output.json
```
